# Investment Portfolio Dashboard

A modern, responsive investment portfolio dashboard built with React, TypeScript, and Tailwind CSS. Features dark mode support, real-time stock tracking, AI-powered analysis, and comprehensive portfolio management tools.

![Dashboard Preview](https://images.unsplash.com/photo-1611974789855-9c2a0a7236a3?auto=format&fit=crop&q=80&w=1200)

## Features

- 📊 Real-time portfolio tracking and visualization
- 🤖 AI-powered stock analysis and insights
- 📈 Stock comparison tools and market trends
- 🌓 Dark/Light mode support
- 📱 Fully responsive design
- 🔒 Secure authentication system
- 📰 Latest market news and updates
- 📊 Asset allocation visualization
- 🎯 Price targets from top analysts
- 📈 Top movers and sector performance

## Tech Stack

- React 18
- TypeScript
- Tailwind CSS
- Zustand (State Management)
- Recharts (Charts)
- Lucide React (Icons)
- React Router DOM

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
